# Background Music Instructions

The website comes with a built-in **Web Audio Ambient Synthesizer** that automatically plays warm, relaxing music-box melody chords (zero external dependencies, zero network lag, works on all devices).

### Want to add your own custom MP3 song?
1. Choose any song or lofi track you like.
2. Rename your file to `birthday-lofi.mp3`.
3. Drop it inside this folder (`public/music/birthday-lofi.mp3`).
4. That's it! When Ashwini clicks the **Play Music** button on the website, it will play your custom MP3 song in a smooth loop.
